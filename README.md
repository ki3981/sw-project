# Caffeine Sleep Simulator ☕

## numpy 기반 카페인 잔량 및 수면 방해 위험도 시뮬레이터

> 카페인 섭취 시간과 양을 바탕으로 시간별 카페인 잔량을 계산하고, 취침 시간의 수면 방해 위험도를 확인하는 파이썬 프로젝트

---

## 프로젝트 소개 📌

이 프로젝트는 하루 동안 섭취한 카페인 음료 정보를 입력하면 시간별 카페인 잔량을 계산하고, 취침 시간에 남아 있는 카페인 양을 기준으로 수면 방해 위험도를 판단하는 프로그램이다.

카페인은 시간이 지나면서 몸속에서 줄어든다. 이 프로젝트에서는 카페인 반감기 공식을 사용하여 카페인이 얼마나 남아 있는지 계산하고, 그래프로 결과를 시각화한다.

## 사용하는 모듈과 역할 🧩

| 모듈 | 역할 |
| --- | --- |
| `numpy` | 시간 배열을 만들고, 카페인 반감기 공식을 배열 전체에 적용하여 시간별 카페인 잔량을 계산한다. |

예를 들어 `numpy`의 `np.arange(0, 25)`를 사용하면 0시부터 24시까지의 시간 데이터를 만들 수 있고, 이 배열에 카페인 반감기 공식을 적용하면 시간별 잔량을 한 번에 계산할 수 있다.

---

## 핵심 계산 공식 🧮

```text
남은 카페인 = 섭취량 x 0.5^(지난 시간 / 반감기)
```

예를 들어 오전 10시에 카페인 150mg이 들어 있는 음료를 마셨다면, 시간이 지날수록 몸속 카페인 양은 반감기 공식에 따라 점점 줄어든다.

## 주요 기능 ⚙️

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| 1 | 카페인 음료 추가 | 음료 이름, 섭취 시간, 카페인 양을 입력한다. |
| 2 | 섭취 기록 확인 | 입력된 카페인 음료 목록을 확인한다. |
| 3 | 시간별 잔량 계산 | 각 음료의 시간별 카페인 잔량을 계산한다. |
| 4 | 전체 잔량 계산 | 여러 음료의 카페인 잔량을 합산한다. |
| 5 | 취침 시간 잔량 확인 | 취침 시간에 남은 카페인 양을 확인한다. |
| 6 | 위험도 판정 | 남은 카페인 양에 따라 수면 방해 위험도를 판단한다. |
| 7 | 그래프 출력 | 시간별 카페인 잔량 변화를 그래프로 출력한다. |
| 8 | 리포트 출력 | 총 섭취량, 잔량, 위험도를 정리하여 출력한다. |

## 사용할 Python 개념 🐍

| Python 개념 | 활용 내용 |
| --- | --- |
| 변수 | 음료 이름, 섭취 시간, 카페인 양, 취침 시간, 반감기 값을 저장한다. |
| 리스트 | 여러 개의 카페인 음료 정보를 저장한다. |
| 딕셔너리 | 음료 하나의 이름, 시간, 카페인 양을 묶어서 저장한다. |
| 조건문 | 취침 시간의 카페인 잔량에 따라 위험도 높음, 주의, 낮음을 판단한다. |
| 반복문 | 입력된 여러 음료를 하나씩 확인하며 카페인 잔량을 계산한다. |
| 함수 | 음료 추가, 잔량 계산, 위험도 판단, 그래프 출력, 리포트 출력을 기능별로 분리한다. |
| 배열 연산 | numpy의 배열 기능을 사용해 0시부터 24시까지의 카페인 잔량을 한 번에 계산한다. |
| 그래프 출력 | 계산한 시간별 카페인 잔량 변화를 그래프로 시각화한다. |
| 입력과 출력 | 사용자에게 음료 정보와 취침 시간을 입력받고 분석 결과를 출력한다. |

---

## 함수 설계 🔧

| 함수 이름 | 역할 |
| --- | --- |
| `add_drink()` | 음료 이름, 섭취 시간, 카페인 양을 입력받아 저장한다. |
| `show_drinks()` | 입력된 카페인 음료 목록을 출력한다. |
| `calculate_remaining_caffeine()` | 한 음료의 시간별 카페인 잔량을 계산한다. |
| `calculate_total_caffeine()` | 여러 음료의 카페인 잔량을 합산한다. |
| `check_sleep_risk()` | 취침 시간 기준 수면 방해 위험도를 판단한다. |
| `plot_caffeine_graph()` | 카페인 잔량 그래프를 출력한다. |
| `print_report()` | 총 섭취량, 취침 시간 잔량, 위험도를 출력한다. |
